TOML 与 JSON YAML 互转合集编码转换

Rust 或 Python 项目配置是 TOML，调接口要 JSON，手改容易漏字段。

TOML 与 JSON YAML 互转合集 是一个即开即用的纯前端免费工具：2 个编码工具同页：TOML 转 JSON、JSON 转 YAML。不需要安装，浏览器打开就能用。

常见问题

需要安装 App 吗？

不需要。浏览器打开链接即可使用，手机和电脑都能用。

我填写的内容会被保存吗？

内容仅用于本次生成。请不要填写身份证号、银行卡号、密码等敏感信息。

支持 [[数组表]] 吗？

支持。数组表会转成 JSON 数组里的对象；嵌套表按 [a.b] 递归生成，错误会指到行号。
