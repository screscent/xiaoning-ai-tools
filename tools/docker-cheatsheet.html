一个具体例子

查日志 → docker logs -f --tail 100 <容器>；清未用资源 → docker system prune -a（危险）；端口不通 → docker port / network inspect；备份卷 → docker run --rm -v vol:/data alpine tar czf - /data；web+db 两服务 → docker-compose.yml 骨架与启动命令。
