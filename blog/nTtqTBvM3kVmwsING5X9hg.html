01SECTION

第 02 篇 · Gemini 2.0：Agent 时代的多模态


02SECTION

导读


2024 年底的行业共识：光会聊天不够，模型得会干活。 OpenAI 有 o 系列，Anthropic 有 Computer Use，Google 则把整个 Gemini 2.0 押在「Agentic」上——同时放出三大件：原生工具调用、计算机使用、实时多模态交互，并在 2.5 上补齐「思考模式」。本篇讲 Google 的 Agent 转向。

03SECTION

一、Gemini 2.0（2024-12）：三件套


1.1 原生工具调用（Function Calling）

•模型直接输出「调用哪个 API + 传什么参数」的结构化指令；

•与搜索、代码执行、Google 服务深度打通——「搜完再用，用完再答」成为默认行为；

•意义：模型从「知识回忆器」变成「能力调度器」（llm-理论 06 的 Agent 三拼图第一块）。

1.2 计算机使用（Computer Use）

•模型能「看屏幕 → 决定操作 → 点击/输入 → 再看结果」地操作真实应用；

•发布时重点场景：浏览器自动化、跨应用任务（订票、填表、整理）；

•与 Claude 的 Computer Use 同期发力——「模型用电脑」成为 2025 年的共同叙事。

1.3 实时多模态

•实时语音/视频对话（看摄像头画面边看边说）；

•低延迟流式输出 + 多语言实时翻译场景——把「多模态」从「看图答题」升级为「实时感知交互」。

💡 学习要点：Gemini 2.0 =「多模态长出手脚」1.x 的多模态是「会看会读」，2.0 的多模态是「看到→操作→验证」闭环。Agent = 多模态感知 + 工具执行 + 循环反馈（llm-理论 06）。

04SECTION

二、Gemini 2.5 Pro（2025-03）：思考模式登场


2.1 Thinking 思考模式

•模型先输出可见的思考过程（一步步推理）再给答案；

•思考深度可调（低/中/高）——成本与精度可权衡；

•与 o1 的关键区别：思考过程对用户可见（OpenAI 保密思维链、DeepSeek-R1 公开、Gemini 走「可见思考」路线）。

2.2 战绩

•LMArena 排行榜榜首连续 6 个月（人类盲评胜率之王）；

•实验版上下文推进到 200 万 token；

•强项：代码、数学、多模态理解、复杂工具链任务全面领先当时竞品。

2.3 为什么「思考可见」重要

•用户能「看懂它为什么这么答」→ 信任与调试能力大增；

•公开思考过程本身也是对齐工具（思考被观察 → 更难藏坏心思）。

05SECTION

三、本篇要点（复习卡片）


1Gemini 2.0 三件套：原生工具调用 + 计算机使用 + 实时多模态——Agent 转向。

2工具调用：模型变「能力调度器」而非「知识回忆器」。

32.5 Pro：Thinking 可见思考模式；LMArena 榜首 6 个月；2M 上下文实验。

4思考路线对照：OpenAI 保密 / R1 公开 / Gemini 可见——「思考透明度」成为路线分歧点。

5Agent 闭环：感知（多模态）→ 决策（思考）→ 执行（工具）→ 反馈（验证）。

06SECTION

四、下一篇预告


第 03 篇：Gemini 3 与 Deep Think——2025-11 的 Gemini 3 Pro 以 1501 Elo 登顶 LMArena，首度发布当日接入 Google 搜索（AI Mode），并推出 Deep Think 超深度思考模式。此后 Flash 系高频迭代到 3.8（含实时语音/图像全家桶）。Gemini 3 = 推理、多模态、生态（搜索/安卓/Antigravity）三位一体的旗舰。
