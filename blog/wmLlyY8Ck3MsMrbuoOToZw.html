05SECTION

三、协议标准化路径（MCP / A2A）


3.1 MCP（Agent ↔ 工具）——05 篇回顾

code

2024-11 Anthropic 开源 → 2025-04 ChatGPT 接入（行业转折）

→ 2025-12 捐赠 Linux Foundation AAIF（与 OpenAI/Google/MS/AWS 共管）

→ 2026-03 月下载 97M / 公共服务器 9400+

→ 2026-07-28 规范 RC（无状态核心 / Tasks / MCP Apps / OAuth 对齐）

3.2 A2A（Agent ↔ Agent）

•Google 2025-04 发布：智能体间任务委派/通信的标准协议；

•2025-06 并入 AAIF（IBM 的 Agent Communication Protocol 合入）；

•与 MCP 分工：MCP = 接工具（毛细血管），A2A = 接同事（大动脉）。

3.3 为什么标准化重要

•一次接入处处可用（MCP 服务器写一次，Claude/ChatGPT/Gemini/Cursor 都能用）；

•集成成本：接一个 SaaS 工具从 18 小时降到约 4 小时；

•去单厂商风险：Linux Foundation 治理 = 生态基础设施（类比 Kubernetes/PyTorch）。

五、本篇要点（复习卡片）


1九大框架按场景分工：LangGraph（可靠）/ OpenAI SDK（轻）/ Claude SDK（编码）/ CrewAI（原型）/ MS AF（.NET）/ ADK（Google）/ LlamaIndex（RAG）/ Pydantic（类型）/ Mastra（TS）。

2选型三步：确定性 vs 灵活性 → 生态 → 多 Agent 复杂度；可观测性第一天开。

3MCP 标准化：2024-11 开源 → AAIF 托管 → 2026-07-28 无状态 RC——工具接入基础设施化。

4A2A 补位：Agent↔Agent；与 MCP 同基金会、分工不同。

5系列收官：构成 × 机制 × 训练 → 应用 → 平台——Agent 原理全景闭环。
