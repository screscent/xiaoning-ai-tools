01SECTION

双机办公，其实有三层协同

▍一句话：双机办公不是"人在两台电脑之间来回切换"，而是三层协同各管一摊——人不折腾、Agent 自己组网、主 Agent 远程指挥。你坐在一台电脑前，剩下的交给分工。

我把一台一备的两台 Mac 摆在桌上，最开始是想解决一个很简单的问题：我不想在两台电脑之间来回切。

后来我发现，真正让"双机办公"顺起来的，不是某一招，而是三层协同各干各的。今天就把这三层一层层拆给你看。

02SECTION

一、第一层：主人这一层——一套键鼠，你只坐一台

其实第一个要解决的是"手"的问题。

用一个叫通用控制的功能：两台 Mac 登录同一个账号，放在同一个 Wi‑Fi 下，打开"允许指针和键盘在附近的 Mac 和 iPad 之间移动"。

装好之后就是这样——鼠标往屏幕边上推过去，1 秒，光标就滑到另一台电脑上。 键盘跟着走，拖文件、复制粘贴文字都是互通的。

对你（人）来说，体验是：你只在一台电脑上操作，另一台像一块"延伸出来的屏"。不用找鼠标、不用抬头换显示器、不用记住哪份文件在哪台机器——它们像一个整体。

通用控制踩坑就几条：两台账号不一致、开了代理、不在同一 Wi‑Fi、蓝牙干扰，都可以直接命中"连不上"。过一遍就能排掉，这里不展开。

但这里有个边界要讲清楚：通用控制是"键鼠互通"，不是远程桌面。 它让你"手"跨机器，但你脑子还在这一台。真正让第二台机器"自己动起来"的，是后面两层。

03SECTION

二、第二层：Agent 这一层——它自己组网，文件协同只是其中之一

如果你只到第一层，那还是"人操作两台电脑"。第二层开始，画风变了——是 AI 自己之间在协作。

我给自己搭了一套网络层（体系里叫 GN 部署拓扑）。它有四种形态：

•GN‑0：单机，没有网络层，我照常在本地干活；

•GN‑1：双机同构，每台机器都是同构的、自带网络叠加层；

•GN‑2：多机组网，一台主控 + 多台执行，网络层全用起来；

•GN‑3：更高级的组网，还在研究方向里。

到 GN‑2，两台机器才真正"组网协同"。这层我拆成了六块协作能力（CL‑1 到 CL‑6）：通信、文件协同、知识共享、日志观测、自治服务、任务编排。

你点的"文件协同"是其中一块（CL‑2），但它不是"把文件拷一份过去"那么简单。核心是三条纪律：

1版本面是唯一真源——哪份文件算数，以一个版本库为准，不靠人人手机里的副本；

2同步面只分发、不回写——自动同步通道只把文件推到机器，收端的东西不会倒灌回去，避免两边越改越乱；

3用哪条通道，项目自己决定——自建版本库、公网版本库、组织内网版本库，都只是"能力集合"，挑哪条由项目自治。

为什么要这么设计？因为"让我在两台机器上手动对齐文件"是件很笨的事。文件协同的意义不是搬运，而是让两台机器从第一天就"看到同一个世界"，且这个世界的唯一真源是明确的。 谁更新了版本库，另一台机器秒级跟上，天然没信息差。

还有一个关键设计：单机不接网络，照常工作。 网络层是"叠上去"的可选增强面，不是强依赖。断网了，我在这台机器里照样把活干完；恢复联网，协同再回来。这是双层体系的底气——协同是增益，不是绑架。

04SECTION

三、第三层：主 Agent 这一层——远程发号施令

第二层让两台机器"数据上对齐"，但还差一件事：怎么让另一台机器上的 AI"动手干活"。

这就是第三层——主控那台机器的 Agent，直接通过 SSH 指挥目标机。 不用你切过去、不用你开屏幕。

比如：把服务部署到备机、在目标机上跑一个校验、同步一份脚本、做一次对账。主 Agent 一条命令过去，目标机的 Agent 接令执行、回报结果，主 Agent 再验收。

这层和第一、二层的关系是层层递进：

•第一层解决"人的手"——你碰得到两台电脑；

•第二层解决"机器之间的数据"——两台看到同一个版本；

•第三层解决"机器之间的执行"——主 Agent 能派活、能验收，目标机不再需要你盯着。

到这一步，"双机办公"就完整了：你坐在主控这台电脑前，键鼠扫过屏幕，AI 在另一台机器上正在替你跑着活、同步着数据、回报着进度。你不是在看两台电脑，你是在指挥一台"分身"。

05SECTION

结尾：三层，缺一不可，也最能说明问题

如果你问"双机办公到底是什么"，我的答案是这三层：

层

解决什么

谁主导

一 · 键鼠互通

你的"手"跨机器

二 · Agent 组网

两台"数据一致"（文件协同只是其一）

三 · SSH 指挥

另台的"执行"可控

最有意思的其实是第二层那句"单机不接网络照常工作"。它像一个隐喻：这套协同不是让我变脆弱，而是让我在需要的时候更强，不需要的时候照常。 一个能进能退的系统，才真的是为人服务的系统，而不是反过来。

我还在一点点把这三层磨顺。如果你也在折腾多台电脑或 Agent 协同，欢迎留言聊聊你踩过的坑。
