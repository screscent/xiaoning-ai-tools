03SECTION

一、CLIP（2021）：让视觉与语言对齐


1.1 问题

图像模型与文本模型各自为政：视觉模型不懂「狗」这个词，文本模型看不到画面。

1.2 CLIP 的做法（OpenAI，2021）

•用**海量「图片-文字对」**做对比学习：让「图片的特征」与「对应描述的文本特征」在向量空间里靠近；

•不需要人工标注类别——直接拿互联网图文对当监督；

•效果：跨模态的「语义对齐」——图与文的距离可计算：看图找描述、按描述找图。

1.3 意义

•证明「视觉 + 语言」可以共用同一个向量空间；

•为「图片进语言模型」铺路：视觉编码器（像 CLIP 的 vision tower）把图片变成 token，喂给文本模型——这就是多模态大模型的雏形。

💡 学习要点：CLIP =「给图片配字幕学习的模型」用「图文对」做对比学习，让两种模态共享语义空间——多模态的第一块基石。

2.2 原生多模态的威力

•看 + 读 + 写：识别图表、读代码截图、看页面布局再生成代码；

•同一套权重理解图文：跨模态推理（「图中这个人像谁？配文说明什么？」）；

•成本：图文混合训练更贵、更复杂——但这是各家旗舰的必经之路（DeepSeek-V4 系列即「百万上下文 + 多模态」双加持，其家族系列第 8 篇深挖）。

💡 学习要点：多模态 =「让模型长眼睛」拼接式像「翻译器」，原生式像「天生会看图的人」。越原生，跨模态理解越深——2025 年后所有旗舰都走原生路线。

05SECTION

三、Agent：从「回答」到「做事」


3.1 为什么需要 Agent 训练

模型再聪明，也只是「对话框里回答问题」。要让它完成真实任务（查资料、写代码、发邮件、操控软件），必须让它学会使用工具。

3.2 三块能力拼图

code

① 工具调用（Function Calling）

   模型学会输出「调用哪个工具 + 传什么参数」的结构化指令

② 规划与反思（Planning & Reflection）

   把大目标拆成子任务，执行后校验结果、自我修正

③ 环境交互（环境反馈）

   工具返回结果 → 模型读结果 → 决定下一步（循环）

•训练方式：工具调用数据 SFT + RL（对齐 + 推理的训练技术直接复用）；

•运行方式：Agent = 模型 + 工具清单 + 循环控制（如 ReAct、代码执行沙箱、浏览器操控）。

3.3 从通用模型到 Agent 体系

•单 Agent：模型 + 工具 + 记忆 → 完成一个任务（写作/编程/查证）；

•多 Agent：多个角色分工协作（规划者/执行者/审查者），如各家的 Orchestrator 编排；

•常驻 Agent：不是「问一次答一次」，而是长期驻留监听（周期巡检、事件驱动）——对应小凝体系的「常驻 goal」形态。

💡 学习要点：Agent =「模型从大脑长出手脚」推理（第 05 篇）解决「怎么想」，Agent 解决「怎么干」：工具 = 手，循环控制 = 腿，记忆 = 档案。2025 年的 AI 竞争已从「谁的模型会说话」转向「谁的 Agent 能干活」。
