03SECTION

二、三条主线：对齐 · Agent · 推理


Anthropic 的进化围绕三条主线交叉推进：

1对齐线（宪法 AI→系统卡→ASL→最对齐）：把「安全原则」写进训练流程、做成可审查的发布制度——对齐优先是公司的 DNA。

2Agent 线（长上下文→Computer Use→Claude Code→Agent SDK）：模型从「会说话」到「自己用电脑干活」，并开放给开发者。

3推理线（3.7 Extended Thinking→4 系列→4.5 混合推理→5.x 自适应）：默认会想、按需深想。

04SECTION

三、关键技术点详解


1. 宪法 AI / RLAIF（Claude 1 的地基）

•人类写原则条文 → 模型自我批评修订（SFT）→ AI 自我打分做 RL；

•与 RLHF 的根本区别：标准从「人工偏好」变「公开条文」——可审查、可迭代、可扩展。

2. 长上下文（Claude 2 → 200K → 1M）

•100K（2023）→ 200K（3.x/4.x）→ 1M（5.x）——读整本书/整个代码库；

•长上下文是 Agent 长程任务（30 小时连续工作）的前提。

3. 三档产品化（Claude 3）

•Opus（最强）/ Sonnet（均衡）/ Haiku（最快）——一次覆盖全部需求；

•教训成行业公式：中间档是产品主战场（对标 GPT mini/nano、Gemini Flash）。

4. Extended Thinking / 混合推理（3.7 → 4.5）

•模型支持快速答 + 按需深想两种模式，思考预算（budget_tokens）可调；

•4.5 升级为 hybrid reasoning：默认会想、按需深想。

5. Computer Use（Claude 4 起爆发）

•模型像人一样操作电脑：看截图 → 点击/输入 → 再看结果；

•OSWorld：Sonnet 4 的 42.2% → Sonnet 4.5 的 61.4%；

•训练：屏幕操作合成轨迹 + RL；应用：Claude for Chrome、桌面自动化。

6. Claude Code 与 MCP（Agent 平台）

•Claude Code：终端编程 Agent（读库/改码/跑测/提 PR）；

•MCP：开放工具接入协议——成为行业「工具接入」事实标准；

•Agent SDK：把底层能力开放给开发者自建 Agent。

7. 对齐的量化与制度化（4.5）

•系统卡评测延伸到奖励黑客、诚实度、agentic 安全、可解释性（mechanistic interpretability）；

•ASL（AI 安全分级）决定能否放行——能力越强门槛越高；

•「最对齐」成为可宣传的卖点：该拒则拒、该干则干。

∞CONCLUSION

四、进化逻辑总结（学习重点）


1对齐做「显式化」：从黑盒偏好打分 → 公开条文 + 系统卡 + 分级制度——安全成为可审查资产。

2能力做「Agent 化」：长上下文 + 计算机使用 + 编程工具 = 从「助手」到「数字员工」。

3推理做「融合」：Extended Thinking → 混合推理 → 自适应思考——对话与思考不分家。

4定价做「下探」：旗舰从高价到 25、Sonnet $2——旗舰能力平民化。

5差异化：对齐优先 × 会干活——与 GPT（产品生态）、Gemini（原生多模态）形成错位竞争。
