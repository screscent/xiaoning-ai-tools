第 02 篇 · GPT-3：1750 亿参数的豪赌与「涌现」

02SECTION

导读

GPT-2 的规模曲线让 OpenAI 认定一件事：架构不用改，规模就是一切。 于是 2020 年他们押下 1750 亿参数的豪赌——比任何公开模型大一个数量级。结果不是「更强一点」，而是出现了「少样本学习」和「能力涌现」两个新物种级现象。这篇是理解「为什么今天所有公司都在堆算力」的根源。

04SECTION

二、三个现象级发现

2.1 少样本上下文学习（Few-Shot / In-Context Learning）

•不给任何梯度更新（不微调），只在 prompt 里给几个示例，模型就能「学会」新任务：0-shot：直接问「翻译成法语：…」1-shot：给一个翻译示例few-shot：给 10 个示例 → 翻译质量逼近专门训练的模型；

•意义：能力从「训练时固定」变成「使用时装配」——这是 Prompt 工程（后来一切 Agent 玩法）的根基。

2.2 能力涌现（Emergent Abilities）

•某些任务（多位数算术、代码生成、答题）在小模型上得分接近 0；

•规模跨过某个阈值后，性能突然跳到可用水平（非平滑上升）；

•意义：无法从小模型外推预测大模型能力——规模带来「质变」而非「量变」。

2.3 知识即参数

•模型「记住」了大量世界知识（人、事、常识）——因为参数本身就是压缩的知识库；

•局限同时暴露：事实错误（幻觉）、陈旧知识（截止时间）、无法「确认来源」。

💡 学习要点：GPT-3 = 缩放定律的「临床试验」Kaplan 2020 论文给出理论曲线，GPT-3 用 1750 亿参数完成了人体试验：loss 按幂律下降、能力涌现、任务可「即插即用」。三个发现全部命中，OpenAI 自此All in 规模化。

05SECTION

三、GPT-3 的「光与影」

3.1 光：验证了路线

•自然语言生成达到「以假乱真」级别（短篇新闻/诗歌/代码）；

•为后续所有产品（API、Copilot、ChatGPT）提供基座；

•让「大力出奇迹」成为行业共识（→ 芯片军备竞赛的源头）。

3.2 影：暴露了三个致命伤

问题

表现

不可控

用户无法让它「乖乖听话」，答非所问、编造、跑题

不安全

中性回答同样可能给出危险/有毒内容（偏见过滤失败）

不会推理

复杂多步数学/逻辑依旧拉胯（规模没解决「思考」）

•结论：光有规模，只能「会说话」，不能「可用」。 这正是 InstructGPT（第 03 篇）的登场理由。

06SECTION

四、与 DeepSeek 的对照（横向视角）

•GPT-3 的教训 = 规模有收益递减：DeepSeek 用 MoE + MLA 在同代实现了「总参数巨大、激活参数小」——知识上限追得上、单次成本砍一半（对应其家族系列 V2 篇）；

•涌现的不可预测性 = DeepSeek 自家缩放研究给出的应对：不盲赌更大，而是算清「token 收益递减点」（对应其家族系列初始版篇）。

07SECTION

五、本篇要点（复习卡片）

1规模数字：1750 亿参数 / 3000 亿 token——当时全球最大。

2少样本学习：不训练、只给示例，任务即插即用 → Prompt 工程之根。

3能力涌现：跨阈值突然变强，无法从小模型外推。

4光：验证「大力出奇迹」，定义行业军备竞赛。

5影：不可控、不安全、不会推理 → 对齐时代的导火索。

08SECTION

六、下一篇预告

第 03 篇：ChatGPT 与 RLHF——OpenAI 用 13 亿参数的 InstructGPT 证明：对齐比参数更值钱（小模型 + 人类反馈 > 大模型裸奔）。2022-11 的 ChatGPT 把「会说话的大模型」变成「听话的助手」，定义产品形态，引爆全球。这是 GPT 系列从「研究」走向「产品」的转折点。
