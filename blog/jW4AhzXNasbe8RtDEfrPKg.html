01SECTION

第 05 篇 · o 系列与 GPT-5：推理、Agent 与大一统

02SECTION

导读

GPT-4 时代的模型是「快思考」：问一句答一句。2024 年 OpenAI 另起一条线——o 系列，让模型先想很久再回答。到 GPT-5，两条线合流：一个模型既会快速对话，也会深度思考，还会调用工具干活。本篇是 GPT 家族现状的终章，也是理解「推理模型」「Agent 模型」这些 2025 年关键词的入口。

03SECTION

一、o1（2024-09）：测试时扩展

1.1 思想

•缩放定律的「算力」不只用于训练，推理时给模型更多思考 token 也能变强（测试时扩展，llm-理论 05）；

•训练方式：RL 强化模型生成隐藏思维链（思考 → 规划 → 校验 → 结论）再给答案；

•效果：数学奥赛、博士级科学题大幅超越 GPT-4；思考时间可调（想越久越准）。

1.2 代价与争议

•慢（一次回答耗几十倍 token）且贵；

•思维链细节被保密（担忧「公开思维过程 = 泄露训练配方/安全风险」）——引发行业关于「开放思考」的讨论（DeepSeek-R1 随后公开完整思维链形成对照）。

04SECTION

二、o3 / o4-mini（2025-04）：推理 + 全工具 Agent

2.1 升级点

•Agentic 工具使用：推理模型第一次能自主组合 ChatGPT 全部工具——联网搜索、Python 分析文件、图像生成、深度视觉理解；

•带图思考：推理过程中「看图」做规划（图表/截图/界面）；

•规模分档：o3（最强）、o4-mini（小/快/性价比，AIME 数学接近满分）。

💡 学习要点：o3 =「会想 + 会动手」的推理 Agent上一代推理模型只「想」不动手；o3 把「想」和「调用工具执行」接到一起——这是 Agent 形态第一次成为推理模型的原生能力。

05SECTION

三、GPT-5（2025-08）：大一统

3.1 核心事实（官方发布）

•API 三档：gpt-5 / gpt-5-mini / gpt-5-nano（按成本/速度/能力分档）；

•编码与 Agent 任务 SOTA：SWE-bench Verified 74.9%、Aider polyglot 88%、τ²-bench 96.7%（工具调用长程任务）；

•特性：推理与对话统一（默认会思考、可调 reasoning effort）、工具调用前后可主动解释、长程任务稳定执行几十次工具调用；

•定位语：「the best model for coding and agentic tasks」。

3.2 与 o 系列的关系

•GPT-5 是「合并产品」：把 o 系列的深度思考能力并入 GPT 主系列——用户不再需要分清「该用 GPT 还是 o」；

•o 系列继续面向「极致深度思考」市场（o3-pro 等），GPT 系列覆盖「通用 + 思考可调」。

•趋势：「默认会想，按需深想」成为 OpenAI 旗舰的默认行为（对应 llm-理论 05 的融合趋势）。

💡 学习要点：GPT-5 系列 =「会思考的 Agent 操作系统」不再是「一个模型」，而是「一个系统」：快速对话 + 深度推理 + 工具调用 + 编码 + 长程任务。能力边界不再由「模型多大」决定，而由「系统能编排多少工具」决定——这正是 Agent 时代（llm-理论 06）的注脚。

07SECTION

五、本篇要点（复习卡片）

1o1（2024）：测试时扩展——思考 token 换精度；思维链保密引发讨论。

2o3/o4-mini（2025）：推理 + 全工具 Agent；带图思考；分档覆盖。

3GPT-5（2025-08）：推理与对话大一统；SWE-bench 74.9%；编码/Agent 任务 SOTA。

4GPT-5.4~5.6：思考计划中途可调、深度研究、旗舰推理系列（5.6 Sol 面向编码/科研/网安/计算机使用）。

5总趋势：从「语言模型」到「会思考、会干活的 Agent 系统」。
