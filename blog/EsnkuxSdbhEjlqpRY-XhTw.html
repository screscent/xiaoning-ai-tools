01SECTION

第 02 篇 · Agent 的推理系统：分解、规划与反思

02SECTION

导读

感知让 Agent「看见」，推理让 Agent「想清楚怎么做」。一个复杂任务（「整理一份行业调研报告」）无法一次生成——必须拆成子步骤 → 规划顺序 → 执行中反思纠错。本篇讲 Agent 推理的三板斧：任务分解、规划与反思，以及推理模型如何把这套能力内化。

03SECTION

一、三大机制

1. 任务分解（Decomposition）

•把大目标拆成可执行的子任务序列（plan-and-execute 模式）：调研报告 → ①定大纲 ②分头查资料 ③分节撰写 ④汇总校对；

•技术：CoT（一步步想）、ToT（树状分支探索）、分解器+执行器分离（planner-executor）；

•意义：长任务的「可执行性」来自分解——模型上下文有限，拆开才能做完。

2. 规划（Planning）

•不只「拆」，还要「选」：生成多个备选方案 → 评估 → 选优（多计划生成与选择）；

•框架化：LangGraph 把规划变成显式图（节点=步骤、边=顺序/分支/重试）——规划从 prompt 变成可控制的程序结构；

•进阶：带反馈的规划——执行一步后根据 Observation 修订后续计划（ReAct 的自然延伸）。

3. 反思（Reflection）

•行动失败/结果不如预期后，生成自然语言反思（错在哪、怎么改），存进记忆供下次参考；

•Reflexion（2023）：反思 + 情景记忆 = 「无语义梯度的 RL」（verbal RL）；

•MIRROR（2025）：反思不只在行动后（inter-reflection），也能在行动前（intra-reflection 预判不良结果）——双记忆（短时+长时）；

•意义：Agent 从「做完拉倒」到「越做越会」——错误成为学习素材。

💡 学习要点：分解 × 规划 × 反思 = 完整推理环分解解决「怎么做完」，规划解决「怎么做对」，反思解决「错了怎么改」。三者配合才是 Agent 的推理系统——只有分解没有反思的 Agent，会在同一个坑里反复掉。

04SECTION

二、推理模型（Reasoning Models）成为 Agent 大脑

2.1 发生了什么

•通用模型时代：推理靠外层 prompt 工程（CoT/ReAct 都是「话术引导」）；

•o1/R1 时代：模型本身被 RL 训练出「先想后答」——思考链成为模型的内部能力（llm-理论 05）；

•GPT-5 时代：推理与工具链合一——模型「边想边调工具」，长程任务几十次工具调用不迷路。

2.2 对 Agent 的三层影响

影响

说明

规划变深

推理模型能生成更长、更可靠的执行计划（o3 的「边想边用工具」）

反思变内化

模型在思考链里自我校验，外层 Reflexion 变成「第二道保险」而非必需

测试时扩展

想越久干越好——「思考预算」成为 Agent 的可调资源（成本换质量）

2.3 注意：推理模型 ≠ 万能

•思考链变长 → 延迟与成本上升（长任务要平衡）；

•推理强但「环境感知/工具操作」仍需感知与行动系统配合——推理只是大脑，不是全部。

05SECTION

三、推理系统的工程实践要点

1分层：粗规划（模型）→ 细执行（确定性流程/脚本）——能确定的部分别让模型「自由发挥」；

2失败回退：每步执行留校验点，失败 → 反思 → 重试（上限控制，防死循环）；

3人机分工：关键决策交人工（HITL），机械步骤交给流程（衔接板块二 07 篇）；

4预算管理：思考预算（reasoning effort）与执行预算（max steps）双控——成本与可靠性的平衡。

06SECTION

四、本篇要点（复习卡片）

1三机制：分解（怎么做完）/ 规划（怎么做对）/ 反思（错了怎么改）——完整推理环。

2Reflexion：反思 + 情景记忆 = verbal RL——不调权重，靠长记性变强。

3MIRROR：行动前反思（预判）+ 行动后反思（纠错）——双记忆双通道。

4推理模型当大脑：o1/R1/GPT-5 内化「先想后干」；思考预算成为可调资源。

5边界：推理只是大脑——感知、行动、记忆仍需配套；成本与延迟要控。

07SECTION

五、下一篇预告

第 03 篇：Agent 的记忆系统——推理要想得对，还得「记得住」。短时记忆（对话上下文）、长时记忆（跨会话持久化）、情景记忆（Reflexion 的经验）、以及上下文工程（Context Engineering）如何对抗上下文窗口的物理限制。记忆 = Agent 从「一次性工具」到「越用越懂你」的关键。
