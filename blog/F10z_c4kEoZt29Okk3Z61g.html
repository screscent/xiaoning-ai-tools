01SECTION

第 7 篇 · DeepSeek-V3.2：稀疏注意力 + 会「用工具」的思考


02SECTION

导读：2025 年的「小步快跑」与最后合流


2025 年是 DeepSeek 的「迭代年」：V3 架构不动，一路小版本累加——V3-0324（2 月，V3 更新）、R1-0528（5 月，R1 更新）、V3.1-Terminus（6 月/9 月更新，缓解中英混杂、优化 Code/Search Agent、统一思考/非思考模型），再到 V3.2-Exp（9 月）与 V3.2 正式版（12 月）。

V3.2 系列干了三件大事：

1DSA 稀疏注意力：把注意力复杂度从 O(L²) 压到 O(L·k)——长上下文从此「算得起」；

2思考融入工具：第一个「边思考边调用工具」的模型，Agent 能力站上开源最高点；

3可扩展 RL：后训练算力投入超过预训练的 10%，配得上「思考」的代价。

而 V3.2-Speciale 直接把推理推到开源天花板：IMO / CMO / ICPC / IOI 四块金牌，ICPC 成绩相当于人类选手第二名。

一句话总结：V3.2 同时补齐了效率、推理、Agent 三块短板，是 V3 时代的收官之作。


03SECTION

一、背景：开源与闭源的差距，反而在扩大


V3.2 技术报告罕见地坦诚：开源模型仍在进步，但闭源（Anthropic/DeepMind/OpenAI）进步更快，性能差距不缩反扩。报告把开源模型的短板归结为三点：

1注意力低效：仍依赖标准稠密注意力，长序列效率受限；

2后训练投入不足：高难度任务上的「思考训练」算力太少；

3Agent 泛化滞后：工具使用、指令跟随与闭源专业模型差距明显。

V3.2 的三个突破，正好逐一对应这三点。

04SECTION

二、DSA：DeepSeek 稀疏注意力（V3.2-Exp 引入）


2.1 问题：MLA 压缩了缓存，但注意力矩阵仍是稠密的

第 3 篇讲过，MLA 把 KV 缓存压缩了 93.3%——缓存变小了。但每个 query 仍要跟所有历史 token 算注意力，复杂度 O(L²)。序列一长（128K、上百万 token），这个平方项就压垮算力与延迟。

2.2 方案：Lightning Indexer + Top-k 选择

DSA 由两个组件构成：

组件
作用
闪电索引器（Lightning Indexer）
一个轻量打分模块，快速估算「当前 query 与每个历史 token 的相关性」；复用 MLA 的压缩 latent，成本极低
细粒度 Top-k 选择
每个 query 只对最相关的 k 个 token（默认 2048）做注意力计算

效果：复杂度从 O(L²) → O(L·k)（k 远小于 L）。长上下文下，训练与推理成本大幅下降——V3.2-Exp 发布当天 API 就降价 50% 以上。

💡 学习要点：DSA = 内容感知的动态稀疏固定稀疏（如滑动窗口）会漏掉远处重要信息。DSA 的索引器是学出来的——它「知道」哪些历史 token 值得看，因此是内容感知的、动态的稀疏。

2.3 两阶段训练（关键工程）

阶段
做法
目的
① 稠密预热（Dense Warm-up）
保持稠密注意力，冻结主模型、只训索引器；用主注意力分布做「老师」，KL 散度对齐，约 1000 步 / 21 亿 token
让索引器学会「模仿」真实注意力的选择
② 稀疏训练（Sparse Training）
打开 top-k 稀疏，全体参数一起训；每 query 选 2048 个 KV，约 15000 步 / 9437 亿 token
让主模型适应稀疏模式

对比验证：V3.2-Exp 与 V3.1-Terminus 训练配置刻意保持一致——分数差异只可能来自注意力机制本身。两个月用户实测「无显著劣化」，验证了 DSA 有效。

💡 学习要点：先教索引器、再放开模型「让选择器先学会选择，再让主模型适应稀疏」——这个两阶段解耦，避免了稀疏引入时的训练崩溃，是 DSA 落地成功的关键。

05SECTION

三、思考融入工具：Agent 能力跃升


3.1 突破点

过往的推理模型「思考模式下不能用工具」。DeepSeek-V3.2 是首个将思考融入工具使用的模型——思考模式与非思考模式都支持工具调用：模型可以多轮「思考 + 调工具」，最终给出更准确、更详尽的回答。

3.2 做法：大规模 Agent 数据合成

•冷启动：沿用 V3 的方法，把「推理」与「工具使用」统一进同一条轨迹；

•大规模合成：构建 1800+ 个环境、85,000+ 条复杂指令，生成大量「难解答、易验证」的强化学习任务；

•官方强调：未针对评测集特殊训练——能力来自泛化而非「背题」。

3.3 成绩

Agent 工具调用评测上，V3.2 达到开源模型最高水平，大幅缩小与闭源差距。

06SECTION

四、可扩展 RL：配得上「思考」的算力投入


•后训练（主要是 RL）计算预算超过预训练成本的 10%——开源模型里罕见的大手笔；

•GRPO 进一步改进：无偏 KL 估计（修正原估计的偏差）、离策略序列掩码等，让大规模 RL 更稳。

💡 学习要点：为什么开源差在「后训练」预训练开源大家都能做；差距在「思考训练」这种烧后训练算力的环节。DeepSeek 敢在开源模型上投入 >10% 的后训练预算，是 V3.2 追平 GPT-5 的底气。

💡 学习要点：同一底座、两种「思考预算」日常任务用 V3.2 的平衡思考（快、省），极限难题用 Speciale 的长思考（贵、强）——思考长度 = 可调的计算预算，这正是「测试时扩展」的落地形态。

08SECTION

六、本篇要点（复习卡片）


1V3 系列 2025 迭代路线：V3-0324 → R1-0528 → V3.1-Terminus → V3.2-Exp → V3.2 正式版——架构不动、能力累加。

2开源三大短板（官方自述）：注意力低效、后训练投入不足、Agent 泛化滞后——V3.2 逐一补齐。

3DSA：Lightning Indexer + Top-k 选择，O(L²)→O(L·k)；两阶段训练（稠密预热教索引器 → 稀疏训练适配）；API 降价 50%+。

4思考融入工具：首个支持思考模式工具调用的模型；1800+ 环境、8.5 万指令的合成数据；未刷评测集。

5可扩展 RL：后训练预算 >10% 预训练；GRPO 无偏 KL 估计等改进。

6双轨：V3.2 平衡（≈GPT-5）、Speciale 极致（≈Gemini-3.0-Pro，四奥赛金牌）。

09SECTION

七、下一篇预告（系列终篇）


V3.2 把效率与 Agent 做到 V3 时代的极限，但注意力 O(L·k) 的「k」与 KV 缓存仍是长上下文的心头刺。下一篇进入 DeepSeek-V4 / V4.1：CSA + HCA 重度压缩注意力、Engram 条件记忆引擎、mHC 流形约束超连接、百万上下文普惠，以及 V4.1 Flash 的原生多模态——两条主线（效率 + 能力）的大结局。
