03SECTION

二、三条主线：多模态 · 上下文 · 生态


Google 的进化围绕三条主线交叉推进：

1多模态线：原生多模态（1.0）→ 视频/实时语音（2.0）→ 全模态 Agent + 图像系（3.x）——「从一开始就在一起」而非后期拼接。

2上下文线：32K → 1M（1.5）→ 2M 实验（2.5）——长上下文霸主，一次装下整个世界。

3生态线：函数调用/搜索（2.0/2.5）→ AI Mode in Search + Antigravity（3）——模型 × 搜索 × 安卓 × 云端叠护城河。

04SECTION

三、关键技术点详解


1. 原生多模态（Gemini 1.0 的定义级差异）

•图文音视频从预训练第一刻联合训练，一套权重内贯通理解；

•对比「拼接式」（视觉塔翻译成 token 再喂文本）：原生式跨模态推理更深；

•影响：宣告「多模态 = 下一主战场」，各家旗舰（GPT-4o/Claude 4/V4）随后全部转原生。

2. 百万上下文（Gemini 1.5）

•100 万 token：一次读整书/整代码库/2-3 小时视频；

•技术：稀疏注意力 + 高效 KV 管理；基建：TPU + 自家数据管道；

•课题：塞得下 ≠ 用得起——长上下文算力成本持续优化（Flash 系对冲）。

3. 思考模式（Thinking / 2.5 Pro）

•可见思考过程（一步步推理再给答案），深度可调；

•与 o1（保密思维链）、R1（公开思维链）形成路线对照——Gemini 走「思考可见」；

•战绩：LMArena 榜首连续 6 个月（人类盲评之王）。

4. Agent 能力（Gemini 2.0）

•原生工具调用（搜索/代码/Google 服务）、计算机使用、实时多模态；

•意义：模型从「知识回忆器」变「能力调度器」——感知（多模态）→ 决策（思考）→ 执行（工具）闭环。

5. Deep Think 与档位矩阵（Gemini 3 / 2026）

•Deep Think：比标准思考更深的推理档（拆解/规划/校验更彻底）；

•档位矩阵：Flash（快/省）× Pro（深）× Live（实时语音）× Image（图像）——全场景全价位覆盖；

•高频迭代：3.1→3.8 半年更替，稳定版常换常新——模型迭代运营化。

6. 搜索生态 day-one（Gemini 3）

•首次在模型发布当日接入 Search AI Mode（实时检索 + 深度推理）；

•Antigravity：agentic 开发平台——模型 × 入口 = Google 独有护城河。

∞CONCLUSION

四、进化逻辑总结（学习重点）


1多模态做「原生」：从预训练就联合，而非拼装——跨模态理解深度是核心竞争力。

2上下文做「碾压」：1M→2M 一次装下——用「阅读量」打差异（配合稀疏注意力控成本）。

3推理做「档位」：Thinking → Deep Think——深度按任务调配（llm-理论 05）。

4生态做「绑定」：搜索/安卓/云端/平台 day-one 接入——模型强不如入口强。

5迭代做「高频」：Flash 系月更——把模型迭代变成日常运营。
