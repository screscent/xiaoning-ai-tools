01SECTION

第 00 篇 · 前深度学习时代：从「词袋」到「序列建模」

02WHY

导读：为什么 LLM 的历史要从「词」讲起

语言模型（LLM）的「L」是 Language——一切从计算机如何表示词开始。本篇是整条理论线的起点：词的表示（离散→分布式）→ 序列建模（无法并行→可以记忆）→ 注意力（为 Transformer 埋下伏笔）。没有这三步，就没有 2017 年的 Transformer 革命。

03SECTION

一、词的表示：从 One-Hot 到词嵌入

1.1 One-Hot（词袋）的问题

早期把词表示成 One-Hot 向量（一个维度代表一个词）：

•维度灾难：词表 10 万，向量就是 10 万维；

•无语义：猫 和 狗 的向量正交，距离为 0——没有「相似词相近」。

1.2 Word2Vec（Mikolov 2013）：分布式表示的诞生

核心思想：用「上下文」学词的向量——出现在相似上下文的词，向量相近。

•CBOW：用周围词预测中心词；

•Skip-gram：用中心词预测周围词。

•效果：king - man + woman ≈ queen 这类向量算术成立——词向量编码了语义关系。

💡 学习要点：分布式表示 = 一切的基础「用上下文学表示」这个思想，从 word2vec 一路延续到 BERT/GPT 的预训练——只是规模从词表换成了整个互联网文本。

04SECTION

二、序列建模：RNN 与 LSTM

2.1 为什么需要序列模型

句子是有顺序的，词袋模型丢掉了顺序。RNN（循环神经网络）让网络逐步读词并携带记忆：

code

h_t = f(W·x_t + U·h_{t-1})

2.2 LSTM（Hochreiter 1997）：解决「长程记忆」

RNN 的梯度消失让「隔很远的词」学不到。LSTM 引入门控（输入门/遗忘门/输出门），让信息可以选择性记住或遗忘——可以记住「这个句子的主语是单数」直到句尾。

2.3 局限（为 Transformer 埋下伏笔）

•串行：必须一个词一个词算，无法并行（GPU 利用率低）；

•长程弱：即便 LSTM，几千步的依赖仍吃力；

•方向性：只能从左往右（单向），看不到后文。

05SECTION

三、Seq2Seq 与注意力（Attention 的诞生）

3.1 Seq2Seq（2014）：编码器-解码器框架

机器翻译的标准框架：编码器把整个源句压成一个向量 → 解码器逐词生成译文。问题：一个向量装不下整句信息，长句翻译崩坏。

3.2 Bahdanau 注意力（2015）：「对齐」思想

注意力（Attention）：解码每一步时，不是只看那个「总结向量」，而是回看源句的每个词、按相关性加权——权重高的词贡献大。

code

attention 权重 = 当前解码状态 与 各源词编码 的相关性

💡 学习要点：Attention = 按相关性加权读取「加权读取」是 2017 年 Transformer 的核心组件。Bahdanau 的注意力还只是 Seq2Seq 的辅助机制，Transformer 把它扶正为唯一机制——这是下一篇的引子。

06SECTION

四、本篇要点（复习卡片）

1词表示三阶段：One-Hot（无语义）→ 分布式（word2vec，用上下文学向量）→ 上下文化表示（下一篇的 ELMo/BERT）。

2序列建模两难：RNN/LSTM 能记顺序但串行且长程弱——这是 Transformer 要解决的痛点。

3注意力诞生：Bahdanau 2015 提出按相关性加权读取，为「Attention Is All You Need」铺路。

4主线：分布式表示 → 序列建模 → 注意力 = 2017 前夜的全部。

07SECTION

五、下一篇预告

第 01 篇是本系列的第一个高潮：Transformer 革命（2017）——为什么「注意力即一切」能干掉 RNN，以及它开启的三大预训练范式：ELMo（双向语言模型）、BERT（双向编码器）、GPT（单向生成式）——三者的分工与较量，直接决定了今天 LLM 的形态。
