04SECTION

二、两个关键概念

2.1 Copilot 范式：人在环（Human-in-the-Loop 的产品化）

•特征：人提供意图、机提供执行——补全、建议、草稿、快捷键式介入；

•原理：最大化「人机互补」——人的判断力 + 机的速度与知识面；

•代表：Cursor（补全+Tab 键确认）、Copilot 提示补全、设计工具 AI 辅助；

•定位：工具增强人——人的生产力放大器（augmentation，不是 replacement）。

2.2 Autopilot 范式：人在环外（或只做熔断）

•特征：机自主执行完整流程，人只设边界与紧急接管（异常/超限才介入）；

•原理：流程足够确定/可验证 → 自主度拉满 → 人做「监督者」而非「操作员」；

•代表：自动驾驶 L3-L4、无人值守批量任务、全自动流水线；

•定位：人让渡执行权，保留控制权——「可控自主」（衔接 agent-系列 07 篇 HITL 原则：自主度 = 可逆程度）。

💡 学习要点：Copilot 与 Autopilot 不是先进落后，是「风险承受度」的两端Copilot 适合「不可逆、高价值、人必须负责」的任务；Autopilot 适合「成熟、可验证、容错高」的任务。中间地带 = 自主 Agent（机主事、人审关键点）——2025-2026 的多数商用产品落在这一段。

05SECTION

三、从 Copilot 到 Autopilot 的迁移路径（渐进自主）

code

阶段 0 对话助手：人全手动

阶段 1 Copilot：机补全，人确认

阶段 2 自主 Agent：机规划执行，人审关键节点（HITL 审批点）

阶段 3 Autopilot：机全流程，人只管边界/熔断

•迁移条件（每升一档要满足）：错误成本可承受（或错误可逆）；结果可验证（有校验器/评测）；护栏到位（Guardrails + 审计，agent-系列 07 篇）；数据/经验积累（足够多成功轨迹支撑信任）。

•启示：自主度不是一步到位，是「证明可靠后逐级放开」——先用 Copilot 模式攒信任，再渐进升档。

06SECTION

四、本篇要点（复习卡片）

1四形态：对话助手（人全权）→ Copilot（人主机辅）→ 自主 Agent（机主人监）→ Autopilot（机全权）。

2Copilot = 工具增强人：人判断、机执行——生产力放大器（Cursor/Copilot）。

3Autopilot = 人让渡执行权、保留控制权：只设边界与熔断。

4中间地带是主战场：自主 Agent（机主事 + 人审关键点）——2025-2026 商用主流。

5渐进自主四条件：错误可逆 / 结果可验证 / 护栏到位 / 经验积累——证明可靠后逐级放开。
