06SECTION

四、实战第一原则（贯穿全系列）


1先单后多：先跑通单 Agent，再上多 Agent（多 Agent token ≈ 15 倍，别一上来就贵）；

2先官方例再魔改：Eino-examples / 官方 cookbook 是事实源，改之前先跑通；

3代码即文档：类型安全（Go）让 Agent 代码可读可维护——这是 Eino 的核心卖点；

4生产五件套：流式 / tracing / 评测 / HITL / 护栏——能跑 ≠ 能上（08 篇展开）。

💡 学习要点：实战地图 =「原理 → 范式 → 框架 → 代码」的最后一公里前面两线给了「脑」，本系列给「手」。动手的正确姿势：先小后大、先官方后魔改、先能跑后能上。

07SECTION

五、本篇要点（复习卡片）


1三线关系：原理（是什么）→ 范式（怎么设计）→ 实战（怎么写）——顺序学习。

2四路径：Go 专线（Eino）/ 通用线（Python）/ 生产线 / 趋势线——按背景选入口。

3Eino 一句话：字节 Go LLM 框架——组件 9 类 + 编排 3 API + ADK 多 Agent。

4实战四原则：先单后多 / 先官方例 / 代码即文档 / 生产五件套。

5本系列结构：00 地图 → 01-03 框架 → 04-07 通用 → 08 工程化 → 09-10 趋势。
