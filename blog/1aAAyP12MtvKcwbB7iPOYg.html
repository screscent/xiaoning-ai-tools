03SECTION

一、神经符号结合的具体模式


1.1 两种范式各自的「强项边界」

•神经（LLM）：语言理解、模式识别、候选生成、常识——流畅但不保证对；

•符号（逻辑/规划器/求解器）：约束满足、一致性检查、正确性证明——严谨但不会理解语言；

•结合原则：神经干它擅长的（理解/生成），符号干它擅长的（约束/验证）。

•关键结论：神经符号不是 LLM 的替代，是「LLM 最弱处（多步逻辑、约束、可审计）」的补丁层。

💡 学习要点：神经符号 = 给 LLM 装「确定性骨架」让 LLM 负责开放探索，符号负责「必须对」的部分——可验证性从「模型自觉」变成「架构保证」（对应工程板块「确定性兜底」在学术层的表达）。

04SECTION

二、Agent 的通用框架（李航 JCST 2026）


李航（字节 Seed）在 JCST 2026 提出覆盖软件 Agent 与机器人的通用信息处理框架：

code

Agent = 任务导向 × (文本/多模态)输入输出 × LLM 推理 × 强化学习构建 × 工具与记忆

2.1 五要素

1任务导向：一切围绕「完成任务」，不是闲聊；

2多模态输入输出：文本/图像/音频/视频——感知层（agent-系列 01 篇）；

3LLM 推理：核心决策用 LLM（agent-系列 02 篇）；

4强化学习构建：行为通过 RL 训练成型（agent-系列 08 篇）——不是纯 prompt；

5工具与记忆：行动靠工具、积累靠记忆（agent-系列 03/04 篇）。

2.2 意义

•把「agent-系列的四系统 + 训练」浓缩成一个统一表述——软件 Agent 和机器人共用同一框架（对应「计算机是大脑，机器人是身体」的观点）；

•MCP 被类比为「Agent 的冯·诺依曼架构尝试」——统一的工具接口是通用框架的硬件层（agent-系列 05 篇）。

四、本篇要点（复习卡片）


1结合原则：神经管理解/生成，符号管约束/验证——各干各擅长的。

2四模式：顺序级联（ATA 防注入）/ 并行协商 / 符号即工具（AlphaGeometry）/ 符号约束生成（合规）。

3通用框架五要素：任务导向 × 多模态 × LLM 推理 × RL 构建 × 工具记忆——软硬件 Agent 统一。

4MCP 的地位：Agent 的「统一接口层」类比（衔接 agent-系列 05 篇）。

5研究收敛方向：神经为体、符号为骨、学习为成长。

6板块二收官：路线之争（04）→ 演进前沿（05）→ 统一框架（06）。
