定位：Agent 原理系列板块一·构成第 03 篇——记忆系统（Memory）。短时/长时/情景记忆如何让 Agent 从「一次性工具」变成「越用越懂你」，以及上下文工程（Context Engineering）如何对抗上下文窗口的物理限制。

免责声明：本文为学习与技术分享用途，技术细节以官方论文与工程文档为准。

01SECTION

第 03 篇 · Agent 的记忆系统：短时、长时与上下文工程

02SECTION

导读

推理（第 02 篇）让 Agent「会想」，但没记忆的 Agent 是「金鱼」：每次对话结束就失忆，长任务做着做着忘了开头。记忆系统解决三件事：这次会话记得住（短时）、跨会话记得住（长时）、犯错的经验用得上（情景）。本篇拆解三类记忆 + 背后的上下文工程。

03SECTION

一、三类记忆

1. 短时记忆（Short-Term / Working Memory）

•指当前会话的上下文：对话历史、中间步骤、工具返回、待办列表；

•载体：上下文窗口本身（token）；框架里的 session/conversation buffer；

•工程：窗口超限时的上下文管理（见第三节）——短时记忆是「最贵」的记忆（每 token 都要重算/重读）。

2. 长时记忆（Long-Term）

•跨会话持久化：用户偏好、项目背景、历史结论——「越用越懂你」的来源；

•载体：向量数据库（embedding 检索）、知识库、文件、结构化档案；

•工程形态：RAG（检索增强，llm-理论 04）、Memory API（各家 Agent 平台的记忆服务）、画像/档案文件；

•关键：不是全存，而是「需要时查」——检索决定回忆质量（相关性/粒度/时效）。

3. 情景记忆（Episodic / Experience）

•记录「具体事件经验」而非知识：上次怎么失败的、哪个工具不好用、用户纠正过什么；

•代表：Reflexion 的 episodic buffer（第 02 篇）——反思文本存下来，下次行动参考；

•进阶：Generative Agents 的「记忆流」（记忆 + 重要性评分 + 周期性反思 + 检索加权）——像人一样「分主次地记住」。

💡 学习要点：记忆三问 = 谁在记 / 记多久 / 怎么取短时记「本次」，长时记「跨次」，情景记「经验」。三者本质相同：都是「存储 + 检索」，区别在生命周期与检索方式。没有记忆的 Agent 是工具，有记忆的 Agent 是「长期共事的同事」。

04WHY

二、为什么记忆难：上下文窗口是物理瓶颈

•上下文窗口有限（128K~1M），但真实任务的「潜在相关信息」无限（整个代码库、全部历史、所有文档）；

•塞不下 → 必须选择性存取——这就是上下文工程（Context Engineering）的课题。

05SECTION

三、上下文工程（Context Engineering）

技术

思路

代表

摘要/压缩

老对话折叠成摘要，释放窗口

Claude Code context editing、GPT-5 上下文压缩

检索

只把「当前相关」片段放进窗口（RAG）

LlamaIndex、向量库

分层窗口

系统提示（恒定）+ 近期对话（完整）+ 远期（摘要）三层管理

各家 Agent 框架默认

检查点/恢复

长任务状态落盘，断点续跑（而非重来）

LangGraph durable checkpointing、Claude Code checkpoints

缓存

不变前缀（系统提示/工具定义）缓存，省重复计费

prompt caching（各家 API）

💡 学习要点：上下文工程 = 给 Agent 做「内存管理」就像操作系统管内存（该缓存的缓存、该换出的换出），Agent 的窗口也要管理。记忆的质量 = 检索质量 × 压缩保真度 × 恢复能力——三块都决定长任务成败。

06SECTION

四、记忆的工程实践要点

1分级存储：热数据（当前任务）进窗口、温数据（近期）进摘要、冷数据（历史）进向量库——成本与速度分层；

2检索增强：记忆查询要带「时间/重要性/相关性」权重（Generative Agents 的做法）；

3写入门控：不是所有经历都值得记——重要/纠正/异常优先持久化（对齐「记忆写入门控」思想）；

4隐私与边界：长时记忆涉及用户数据——留存范围、可删除、权限边界必须设计（衔接板块二 07 安全篇）。

07SECTION

五、本篇要点（复习卡片）

1三记忆：短时（本次会话）/ 长时（跨会话持久）/ 情景（经验教训）——都是「存储+检索」。

2Reflexion 情景记忆：反思文本 + 记忆流——Agent「越做越会」的机制。

3Generative Agents 记忆流：重要性评分 + 周期反思 + 加权检索——像人一样分主次记忆。

4上下文工程五技：摘要 / 检索 / 分层窗口 / 检查点恢复 / 缓存——对抗窗口瓶颈。

5分级原则：热进窗口、温进摘要、冷进向量库——成本与速度分层。

08SECTION

六、下一篇预告

第 04 篇：Agent 的行动系统——想清楚、记得住之后要「干得出去」：工具调用（Function Calling）、代码执行（沙箱）、界面操作（Computer Use 点击/键入）、以及行动安全（授权与权限最小化）。行动 = Agent 从「大脑」到「手脚」的最后一环。
