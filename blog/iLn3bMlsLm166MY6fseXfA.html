01SECTION

第 4 篇 · DeepSeek-V2.5：不换架构的「All-in-One 加固」

02WHY

导读：为什么值得专门看一个「小版本」

DeepSeek-V2.5 没有新论文、没有新架构，但它在 DeepSeek 的发展节奏里代表了一种重要的方法论：「模型能力分立 → 合并收敛」的整合路线。

它把当时两个并行的模型——通用对话的 DeepSeek-V2-Chat 和代码专用的 DeepSeek-Coder-V2——合并成一个 All-in-One 模型。这件事的价值远超「省一个部署」：

1它验证了底座架构（MLA + MoE）的通用性：同一套底座既能训通用，也能训代码，还能合并；

2它确立了 DeepSeek 之后一贯的做法：小步快跑、后训练优化、按偏好对齐迭代，而不是每次都要重训架构；

3它把「安全与有用」的边界理清了——安全分提升的同时，安全策略「外溢误伤」反而下降。

一句话总结：V2.5 是「架构已定、专心调教」的示范，也是通往 V3 之前的一次重要整备。

03SECTION

一、背景：能力「分立」带来的痛点

到 2024 年中，DeepSeek 手里有两套强模型：

•DeepSeek-V2-Chat：通用对话强（写作、问答、推理）；

•DeepSeek-Coder-V2：代码能力强（代码生成、补全、跨文件理解）。

痛点：用户要「通用」和「代码」时得在模型之间切换；API 与部署也要维护两套。业界需要的是一个模型既会聊天又会写代码。

💡 学习要点：合并的前提是「各自都补齐短板」直接合并两个偏科模型没用。DeepSeek 先让对话版学代码（换底座）、再让代码版学通用（对齐），两边都补到位了，合并才成立。「先互补、再合并」是这类整合的标准动作。

05SECTION

三、V2.5 的四项关键变化

1All-in-One 合并：保留 Chat 的通用对话能力 + Coder 的强大代码能力，一套模型全部覆盖；API 向前兼容（deepseek-coder / deepseek-chat 均指向新模型），Function Calling、FIM 补全、JSON 输出等功能保持不变。

2人类偏好对齐：更贴近人类偏好（对齐是后训练阶段的核心优化方向）。

3写作与指令跟随大幅提升：创作类任务与指令遵循能力显著变好。

4安全边界清晰化：强化抗越狱能力，同时减少安全策略对正常问题的过度泛化。

06SECTION

四、评测结果（官方发布说明）

4.1 通用能力

在多个中英文标准测试集上，V2.5 全面优于合并前的两个版本（V2-0628 与 Coder-V2-0724）；内部中文评测中，对 GPT-4o mini / ChatGPT-4o-latest 的对战胜率显著提升（裁判为 GPT-4o），覆盖创作、问答等通用场景。

4.2 安全能力：更安全，且「不误伤」

💡 学习要点：安全 ≠ 越严越好安全策略太激进会「误伤」正常提问（外溢）。V2.5 同时做到安全分 +8.2、外溢 -6.7 个百分点，靠的是把安全边界定义得更精确，而不是一刀切。这是后训练阶段「边界管理」的典型目标。

4.3 代码能力

•保留 Coder-V2-0724 的强代码能力；

•HumanEval Python、LiveCodeBench 有显著提升；

•FIM（中间补全）任务提升 5.1%（内部 DS-FIM-Eval）——插件补全体验更好；

•局限：SWE-verified（真实软件工程修复）仍偏低，团队明言「仍需优化」——为后续 Agent 方向的迭代埋了伏笔。

07SECTION

五、架构不变，靠什么「加固」

V2.5 没有动架构（仍是 236B 总参 / 21B 激活 / 128K 上下文 的 MLA + MoE），所有提升来自后训练管线：

•更高质量的 SFT 数据（通用 + 代码混合配比）；

•更强的偏好对齐（写作、指令跟随）；

•更精细的安全对齐（边界清晰化）。

💡 学习要点：模型迭代的两个层次① 架构层迭代（V2→V3→V4）：动底座，能力天花板提升；② 后训练层迭代（V2.5、各小版本）：不动底座，把已有能力「调顺、调安全、调对齐」。DeepSeek 两轨并行，所以版本节奏快且稳。

08SECTION

六、本篇要点（复习卡片）

1V2.5 = 合并：DeepSeek-V2-Chat × DeepSeek-Coder-V2 → All-in-One 模型（2024-09-05）。

2合并三步走：对话版换代码底座（0628）→ 代码版补通用对齐（0724）→ 正式合并。

3四项变化：通用+代码合并、人类偏好对齐、写作/指令跟随提升、安全边界清晰化。

4安全成绩：安全分 74.4%→82.6%，安全外溢 11.3%→4.6%——更安全且不误伤。

5代码成绩：HumanEval/LiveCodeBench 提升、FIM +5.1%；SWE 修复仍弱（埋 Agent 伏笔）。

6方法论：架构不动、后训练加固——「小步快跑」的迭代范式自此确立。

09SECTION

七、下一篇预告

V2 系列到此「调教完毕」。下一篇是本系列第一个「重头戏」：DeepSeek-V3（671B / 37B 激活）。它把 MLA + MoE 推到新规模，并一次引入多项硬核创新——无辅助损失负载均衡、MTP 多 Token 预测、FP8 混合精度、DualPipe 计算通信重叠——最终以 2.788M H800 GPU 小时的训练成本（当时约 557.6 万美元）对齐闭源顶级模型，堪称「效率巅峰」。
