03SECTION

一、Eino 是什么（官方定位）


•一句话：字节跳动开源的 Go 语言 LLM 应用开发框架（CloudWeGo 旗下，Apache-2.0，当前 v0.8.0）——覆盖 LLM 应用 DevOps 全流程（开发/调试/追踪/评测）；

•血统：借鉴 LangChain/LlamaIndex/Google ADK 的设计，但按 Go 惯例重做——强类型、可读、可靠；

•背书：豆包、抖音、扣子等多业务线、数百服务内部接入，内外用一套代码。

💡 学习要点：Eino =「把 LLM 应用工程的坑，用强类型堵住」Go 的接口 + 泛型让「组件输入输出是什么」编译期就明确——代码即文档。Python 拼起来快，Go 改起来稳。选型：快原型用 Python，上生产服务用 Go。

二、9 类组件抽象（队员清单）


Eino 的每个组件是 Go 接口：固定输入输出类型 + Option + 方法签名。官方实现覆盖主流：

•使用范式：先决定「要哪个组件抽象」（我需要一个前锋），再选「哪个实现」（谁当前锋）——抽象与实现分离。

05SECTION

三、最小实战：单独用 ChatModel


go

import (

    "github.com/cloudwego/eino-ext/components/model/openai"

)


func main() {

    // 创建一个可调用的 LLM 实例（OpenAI 实现）

    model, _ := openai.NewChatModel(ctx, &openai.Config{

        APIKey: os.Getenv("OPENAI_API_KEY"),

        Model:  "gpt-4o",

    })


    // 直接调用：输入消息数组，得到模型输出

    message, _ := model.Generate(ctx, []*schema.Message{

        schema.SystemMessage("you are a helpful assistant."),

        schema.UserMessage("what does the future AI App look like?"),

    })

    println(message.Content)

}

•关键：Generate（一次性）/ Stream（流式，返回 StreamReader[*Message]）/ BindTools（绑定工具）三个方法——单组件就能跑通 LLM 调用。

💡 学习要点：先跑通「组件单独用」，再学「编排」单独用 = 一个 ChatModel 一个调用；编排 = 多个组件连成图。别跳过第一步——先确认「队员能踢」，再谈「阵型」。

五、本篇要点（复习卡片）


1Eino：字节 Go LLM 框架（Apache-2.0，v0.8.0）——豆包/抖音在用，覆盖 DevOps 全流程。

2为什么 Go：强类型（代码即文档）/ 性能单二进制 / 流式一等公民 / 生产服务友好。

39 组件：ChatModel/Tool/Retriever/ChatTemplate/Loader/Transformer/Indexer/Embedding/Lambda——抽象与实现分离。

4三方法：Generate（一次）/ Stream（流式 StreamReader）/ BindTools（绑工具）。
