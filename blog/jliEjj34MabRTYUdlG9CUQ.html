02SECTION

导读


前 9 篇的 Agent 都是「被动型」：你发指令它干活。2026 年的代际变化是「主动型」：Agent 自己判断该干什么、主动跟你商量、7×24 后台推进任务。OpenAI Dots 与 Meta Muse 是这波「Agent 2.0 / 个人智能体」的代表。本篇拆解它们的产品形态与技术底座，以及给自建 Agent 的启示。

04SECTION

二、OpenAI Dots 拆解（2026-09）


•形态：个人 Agent + 云端虚拟机（自己的电脑和浏览器）——7×24 后台自主推进任务；

•能力：跨应用操作（已支持 4000+ 应用连接）、主动检查夜间邮件并提醒、董事会前自动更新 PPT、供应商违约自己找替补再请示；

•互动：ChatGPT 发消息/通话、Slack/Teams 触达、未来短信；

•企业版：Specialist Dots——有企业身份/凭证/权限，长期负责某岗位（邮件营销/会计/法律分析）；微软 Microsoft Agent 365 可管理；

•配套：ChatGPT Space 协作空间——用户、同事、多个 Agent 在同一文档协作，@ 一下派活；

•定价：Pro/Business/Enterprise 开放，约 **
20/月档）。

💡 学习要点：Dots =「打开权限 + 云端底座 + 主动商量」三件套①云端虚拟机 = 7×24 运行与跨应用权限；②主动判断 = 自己找活干；③主动商量 = 高风险/决策前回来问你（HITL 从「审批」变「共事」）。Agent 2.0 的核心不是更聪明，是「更主动 + 更自主 + 更共事」。

06SECTION

四、对未来 Agent 开发的启示（实战视角）


1常驻底座：个人 Agent = 09 篇「常驻 Agent」的产品化——云端容器 + 事件监听 + 状态持久化（幂等/去重/健康检查全套要上）；

2主动权限设计：跨应用操作 = 权限面巨大——授权最小化 + 每动作可审计是生死线（agent-系列 07 篇）；

3「共事」式 HITL：不是「每步问」，而是「关键决策回来商量」——打断密度是产品体验核心参数；

4多 Agent 团队化：多个 Specialist Dots 协作（管日程/财务/项目）——对应多 Agent 编排（agent-系列 06 篇）进入个人生活场景；

5平台化：ChatGPT Space = Agent 与人的「协作空间」——未来办公/生活的界面。
