02SECTION

导读：两条主线的「大结局」

从 2024 年 1 月的初始版算起，DeepSeek 用两年多走完了本系列的全部旅程。V4 是效率架构线（V1→V2→V3→V4）的终点站，也是推理/能力线（R1→V3.2→V4）的收束点：

•注意力第三次革命：CSA + HCA 混合压缩，百万 token 上下文从「奢侈品」变「标配」；

•记忆架构创新：Engram 条件记忆引擎——存算解耦，把知识「书架」搬出 GPU；

•训练稳定性革命：mHC 让万亿参数深网络稳定收敛；

•原生多模态：V4.1-Flash 能「看」了，且读得快、写得准。

一句话总结：V4 时代，DeepSeek 把「百万上下文 + 强推理 + Agent + 视觉」全部普惠到开源。

04SECTION

二、架构三大创新（V4 论文：arXiv:2606.19348）

2.1 CSA + HCA：注意力第三次革命

V2 的 MLA 压缩了缓存大小，V3.2 的 DSA 稀疏了计算范围，V4 再进一步——在 token 维度上压缩 KV，并把 DSA 集成进混合注意力：

机制

全称

做法

分工

CSA

Compressed Sparse Attention（压缩稀疏注意力）

连续 4 个 token 的 KV 合并为 1 个聚合单元，过滤局部冗余，再配合 Lightning Indexer 稀疏选择

管「近处细看」

HCA

Heavily Compressed Attention（重度压缩注意力）

远距离 token 做 128 倍高压缩二次聚合，只对「核心摘要」做全局注意力

管「远处宏观」

「长短结合」的效果（100 万 token 上下文）：

•单 token 推理 FLOPs 降至 V3.2 的 27%；

•KV 缓存占用降至 10%；

•直观对比（同为 100 万字上下文）：Llama3.1 需 274GB KV 缓存、GLM-5 需 60GB、DeepSeek-V4 仅 5.48GB。

💡 学习要点：注意力压缩的三级跳MLA（压缓存）→ DSA（压计算）→ CSA/HCA（token 维度压 KV + 分级注意力）。每一级都建立在上一级之上——本系列的「注意力做压缩」主线，至此封顶。

2.2 mHC：流形约束超连接（2026-01，arXiv:2512.24880）

•问题：参数量到万亿级，网络极深，传统残差连接会信号爆炸或消失，训练不稳。

•做法：信息混合的可学习矩阵强制投影到「双随机矩阵流形」（每行每列之和为 1），配合 Sinkhorn-Knopp 归一化——信息在前向/反向传播中既不爆炸也不消失。

•效果：信号增益从 3000 倍压到 1.6 倍以内；1.6T 模型训练收敛稳定性提升 3.2 倍，额外开销仅 6.7%。

•源流：在字节 Seed 的 Hyper-Connections（HC，ICLR 2025）基础上改进，解决 HC 的规模化瓶颈。

💡 学习要点：mHC 是「加深度」路线的钥匙本系列第 1 篇就提到 DeepSeek「加深度不加宽度」；到万亿参数，深度路线终于需要新的连接拓扑兜底——mHC 就是这套兜底。

2.3 Muon 优化器

引入 Muon 优化器：收敛更快、训练更稳定（结合 Hybrid Newton-Schulz 迭代等工程实现），进一步降低万亿参数训练难度。

05SECTION

三、Engram 条件记忆引擎（2026-01，arXiv:2601.07372）

•思想：存算解耦，模拟海马体——GPU 显存是「书桌」，只放当前思考要用的知识；静态知识放「书架」（CPU 内存/SSD）。

•做法：N-gram 哈希 + 近似最近邻检索，实现 O(1) 级召回（tokenizer 压缩、多头哈希、上下文感知门控、多分支集成）。

•效果：Multi-Query NIAH 从 84.2% → 97.0%；静态知识查询快 100 倍、能耗降 90%。

💡 学习要点：记忆 ≠ 参数参数里存的「知识」也可以搬到外部存储，用时再取。Engram 把「学到的知识」和「正在用的知识」分开管理——这是长上下文普惠背后的存储革命。

06SECTION

四、V4.1-Flash：原生多模态 + 更激进的压缩（2026-09-10）

4.1 定位

V4.1-Flash 是新架构家族的最小成员，原生多模态（视觉理解），设计目标：能力上限更高、推理更快、吞吐更大、可扩展。全新非对称模型结构。

4.2 三大关键设计

设计

全称

要点

CED

Causal Encoder-Decoder（因果编码器-解码器）

40 层主干拆成 20 层编码器 + 20 层解码器：prefill 只激活 8B/token、decode 激活 16B/token——读输入便宜、写输出精准（Agent 输入:输出可达 154:1）

CSA2

Compressed Sparse Attention 2

沿层维度跨层复用 KV 与索引（Full/Reindex/Reuse 三种模式，一层干活、多层抄作业）

FP4 缓存

FP4 KV Cache

全局 KV 缓存压到 890 字节/token（约为 V4-Flash 的 1/4），持久化缓存降至约 1/8

架构也集成了 mHC、Engram、DSpark，并支持 1M 上下文。

4.3 成绩（公开基准）

GPQA-Diamond 90.9、HLE 36.8、Codeforces Rating 3471、MathArena Apex 65.6、Terminal-Bench 2.1 90.6、DeepSWE v1.1 74.2、Chartography（视觉）78.9、BabyVision 89.6——纯文本与多模态 Agent 双强。

💡 学习要点：为 Agent 而生的不对称结构传统模型输入短输出长；Agent 恰恰相反（读几十万 token、输出几行补丁）。CED 的「prefill 便宜、decode 精确」就是为 Agent 工作负载量身定制——架构跟着使用场景走。

∞CONCLUSION

五、系列总结：DeepSeek 的进化逻辑（学习闭环）

至此，本系列 8 篇全部完成。回头看，DeepSeek 的两条主线早已贯通：

1参数做「加法」，激活做「减法」：MoE（V2 起）——总参量能大就大，激活量能省就省。

2注意力做「压缩」：MLA → DSA → CSA/HCA——KV 缓存与长上下文算力层层压缩。

3训练做「省钱」：FP8 + DualPipe + 无 aux-loss + Muon——前沿模型成本降两个数量级。

4推理做「强化」：GRPO 纯 RL 让模型自发「想」——推理是 RL 涌现的，不是 SFT 教出来的。

5能力做「多模态 + Agent」：V3.2 思考融入工具，V4.1 原生视觉——从「会说话」到「会做事、会看」。

回顾路径：初始版打地基（Scaling Law）→ Math 发明 GRPO → V2 架构转折（MLA+MoE）→ V2.5 整合加固 → V3 效率巅峰 → R1 推理突破 → V3.2 稀疏 + Agent → V4/V4.1 百万上下文 + 多模态。每一篇都是下一篇的伏笔。
