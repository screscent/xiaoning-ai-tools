02SECTION

导读

07 篇的轴是「人机权力」（Copilot→Autopilot），本篇的轴是「流程确定性」（固定工作流 vs 动态 Agent）。两条轴交叉，就得到 2025-2026 行业落地的最佳实践：能确定的用工作流、该动态的用 Agent，混搭是主流。收尾篇把范式接回「生意」。

•官方建议（Anthropic《Building Effective Agents》观点）：先问「能不能用工作流解决」——确定性优先；只有需要动态决策才用 Agent。

•落地铁律：任务越「可验证、高频、规则化」，越该往「工作流 + 机主导」走；任务越「开放、一次、非结构化」，越该「Agent + 人监督」。

05SECTION

三、行业落地范式（2026 商用元年实录）

行业场景

范式选择

实录

研发评审

工作流 + Agent 辅助

江汽 DFMEA 评审智能体：Agent 查规范/提建议，工程师判断拍板（闭环评审）

质量检测

确定性模型（CV）+ 流程

华为盘古 CV 质检大模型：130 万图训练，一套模型多场景，99.9% 精度

办公自动化

Agent + 工作流混搭

邮件/报表/会议纪要：固定步骤走流程、开放内容走 Agent

编码全流程

Agent（自主）+ HITL

Claude Code / Qwen3-Coder：读库→改码→跑测，人审关键节点

客服/搜索

对话 Agent + 检索

研究 Agent（Deep Research）、智能客服：检索确定性 + 生成动态性

•共性：都是「确定性骨架 + 动态 Agent 局部」——骨架保证可控与合规，Agent 处理非结构化部分。

💡 学习要点：2026 的落地范式 = 工作流为骨、Agent 为肉、人工为关口纯工作流太僵、纯 Agent 太险。生产级方案三合一：工作流管确定性步骤、Agent 处理开放环节、人工在关键节点把关（衔接 agent-系列 07 篇三层防线）。

•三视角合起来的范式选择口诀：任务开放 → ReAct 探索；任务复杂 → P&E 规划；流程固定 → Workflow；要保证 → 神经符号兜底；要成长 → 自进化机制；人负责高价值不可逆 → Copilot 模式；流程成熟可验证 → Autopilot 模式。

07SECTION

五、本篇要点（复习卡片）

1工作流 vs Agent：确定性 vs 动态；能确定的别用 Agent（Anthropic 建议）。

2落地矩阵：两条轴（人机权力 × 流程确定性）交叉 = 行业方案四象限。

3三合一范式：工作流为骨 + Agent 为肉 + 人工为关口——2026 生产级标配。

4行业实录：评审（Agent 辅助人拍板）/ 质检（确定性 CV）/ 办公（混搭）/ 编码（自主+HITL）。

5系列收官口诀：开放→ReAct；复杂→P&E；固定→Workflow；要保证→符号；要成长→自进化；高价值→Copilot；成熟→Autopilot。
