•落地铁律：任务越「可验证、高频、规则化」，越该往「工作流 + 机主导」走；任务越「开放、一次、非结构化」，越该「Agent + 人监督」。

•共性：都是「确定性骨架 + 动态 Agent 局部」——骨架保证可控与合规，Agent 处理非结构化部分。

💡 学习要点：2026 的落地范式 = 工作流为骨、Agent 为肉、人工为关口纯工作流太僵、纯 Agent 太险。生产级方案三合一：工作流管确定性步骤、Agent 处理开放环节、人工在关键节点把关（衔接 agent-系列 07 篇三层防线）。

07SECTION

五、本篇要点（复习卡片）


1工作流 vs Agent：确定性 vs 动态；能确定的别用 Agent（Anthropic 建议）。

2落地矩阵：两条轴（人机权力 × 流程确定性）交叉 = 行业方案四象限。

3三合一范式：工作流为骨 + Agent 为肉 + 人工为关口——2026 生产级标配。

4行业实录：评审（Agent 辅助人拍板）/ 质检（确定性 CV）/ 办公（混搭）/ 编码（自主+HITL）。

5系列收官口诀：开放→ReAct；复杂→P&E；固定→Workflow；要保证→符号；要成长→自进化；高价值→Copilot；成熟→Autopilot。
