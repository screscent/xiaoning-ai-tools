02WHY

导读：为什么 V3 震惊全球

2024 年底，DeepSeek-V3 发布时最炸裂的不是它的性能——而是它的价格：

•671B 总参数的 MoE 模型，完整训练只花了 2.788M H800 GPU 小时，按市价约 557.6 万美元；

•性能却对齐当时最顶尖的闭源模型 GPT-4o 与 Claude-3.5-Sonnet，多项基准超过 Llama-3.1-405B。

整个行业第一次看到：「前沿模型不一定需要无限堆 GPU」。这背后是四层硬功夫：架构创新（无辅助损失负载均衡 + MTP）+ 低精度训练（FP8）+ 训练框架革命（DualPipe）+ 数据/长上下文工程。

一句话总结：V3 把「算法、框架、硬件」三层优化拧成一股绳，把前沿模型训练成本打下一个数量级。

04SECTION

二、创新一：无辅助损失负载均衡（Aux-Loss-Free）

2.1 传统 MoE 的「专家闲置」难题

MoE 要让路由专家都干活，否则闲置专家学不到东西。主流做法是加辅助损失（aux-loss）惩罚不均衡——但辅助损失本身会干扰主任务训练目标，属于「为了均衡而牺牲性能」。

2.2 V3 的做法：偏置项动态调节

V3 首创性地去掉辅助损失，改用每个专家的偏置项（bias）动态调节：

•路由器用 sigmoid 门控给每个 token 打分选专家；

•每个专家带一个可学习的偏置项，负载偏高就调低该专家的分、负载偏低就调高；

•整个过程只动偏置、不加损失项——均衡效果保留，主目标训练却「干净」了。

💡 学习要点：为什么要消灭 aux-loss辅助损失本质是给优化目标「加干扰」。V3 用「工程技巧（偏置调节）」替代「数学惩罚」，既稳住了负载，又不污染训练——这是 DeepSeek「追求干净训练」的典型风格。

05SECTION

三、创新二：MTP 多 Token 预测

传统 LLM 每次只预测下一个 token。V3 引入 MTP（Multi-Token Prediction）：在一次前向里，同时预测后面多个 token。

收益

说明

训练信号更密集

每个位置获得多个监督信号，数据效率更高

更好的表征规划

模型要为「未来」做规划，表征更前瞻

推理加速副产物

MTP 模块可用于投机解码（speculative decoding），加速生成

实测：MTP 对评估基准整体有可量化的提升（V3 报告含消融验证）。

💡 学习要点：多任务头的通用妙用同一个前向算力，多预测几个 token 等于「白拿」额外监督。这个「顺手多做事」的思路，后来在推理侧也反复出现（如多轮验证）。

06SECTION

四、系统工程：三把「省钱」利器

4.1 FP8 混合精度训练（低精度革命）

•训练全程用 FP8 做计算与存储，配合块级量化（128×128 块）+ 高精度乘法累积保住数值精度；

•效果：训练加速 + GPU 显存占用下降，且首次在 671B 这样的超大规模上验证可行；

•顺带开源原生 FP8 权重，社区（SGLang/LMDeploy）第一时间支持原生 FP8 推理。

4.2 DualPipe：计算与通信「重叠」

•流水线并行的痛点是「气泡」（某阶段算、其他阶段等）。

•DualPipe 让计算与通信重叠，气泡大幅减少；MoE 的跨节点 All-to-All 通信被近乎隐藏。

•关键设计保证：只要「计算/通信比」恒定，模型再大也能用细粒度专家而通信开销趋近于零。

4.3 通信内核 + 免张量并行

•自研跨节点 All-to-All 通信内核，吃满 InfiniBand 与 NVLink 带宽；

•精细内存优化后，训练无需昂贵的张量并行（TP）——进一步省硬件成本。

💡 学习要点：成本是「算法 + 框架 + 硬件」三层的合力FP8 省精度开销、DualPipe 省等待时间、免 TP 省硬件需求——没有哪一项单独能造成「5 倍差距」，是三层同时优化才把成本压下来的。

07SECTION

五、训练：14.8T token + 超稳定

•数据：14.8T 高质量多源 token 预训练。

•长上下文两阶段扩展：第一阶段扩到 32K，第二阶段到 128K。

•稳定性：全程无不可恢复的 loss 尖峰、零回滚——规模化训练稳定性的标杆。

•后训练：SFT + RL（GRPO），并对齐人类偏好；还从 DeepSeek-R1 系列蒸馏推理能力（R1 蒸馏的伏笔在这里已经出现）。

•生成速度：20 TPS → 60 TPS，较 V2.5 提速 3 倍。

09SECTION

七、评估成绩

•开源内：多项基准超越 Qwen2.5-72B 与 Llama-3.1-405B。

•对标闭源：与 GPT-4o、Claude-3.5-Sonnet-1022 不分伯仲。

•分领域亮点：代码：Codeforces 算法竞赛大幅领先所有非 o1 类模型；SWE-bench Verified 逼近 Claude-3.5-Sonnet；数学：AIME 2024 / MATH / 高中数学联赛全面领先开源闭源；知识/长文本：MMLU-Pro 75.9、GPQA-Diamond 59.1、MATH-500 90.2；长文本（DROP/FRAMES/LongBench v2）平均超越。

•API 价格：发布即大幅降价（百万输入 0.5/2 元、输出 8 元，优惠期更低）——「性能对齐闭源、价格打穿行业」。

10SECTION

八、本篇要点（复习卡片）

1规模：671B/37B，激活率 5.5%；61 层（3 稠密 + 58 MoE）；1 共享 + 256 路由专家、激活 8。

2无辅助损失负载均衡：sigmoid 门控 + 专家偏置动态调节，去掉 aux-loss 的「性能污染」。

3MTP 多 Token 预测：训练信号更密、表征更前瞻，还能做投机解码加速推理。

4FP8 混合精度：块级量化 + 高精度累积，超大规模首次验证；训练加速 + 显存下降。

5DualPipe + 通信内核：计算通信重叠、跨节点 All-to-All 近乎零开销、免张量并行。

6成本：预训练 180K H800 小时/1T token；全程 2.788M 小时 ≈ 557.6 万美元；训练零回滚。

7后训练：SFT + RL（GRPO）+ 从 R1 蒸馏推理能力；生成速度 20→60 TPS。

8成绩：开源最强、对标 GPT-4o / Claude-3.5-Sonnet，代码/数学领先。
