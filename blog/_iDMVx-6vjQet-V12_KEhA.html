第 04 篇 · 符号 vs 神经双血统：Agent 的路线之争


02SECTION

导读


工程板块讲「怎么搭」，研究板块讲「为什么这么设计是对的」。Agent 的学术谱系有两条血统：符号派（从 1950s 的逻辑/规划走来）和神经派（从统计学习/深度学习走来）。LLM Agent 看似「全新」，其实是神经派借 LLM 爆发后的产物，且正在与符号派重新融合。读这篇能预判范式往哪走。

03SECTION

一、双血统的底子


1.1 符号派（Symbolic/Classical Lineage）

•基础：MDP/POMDP（马尔可夫决策过程）、BDI（信念-愿望-意图认知架构）、SOAR、规划器（PDDL）、约束求解；

•特点：确定性、可验证、可解释——决策基于显式状态与规则，输出有保证；

•局限：规则靠人工维护、无法理解自然语言、面对开放世界僵化。

1.2 神经派（Neural/Generative Lineage）

•基础：深度强化学习（DRL）、LLM；

•特点：泛化、自适应、理解自然语言——从海量数据学出模式，处理开放式问题；

•局限：幻觉、不可审计、易注入、推理链一长就丢。

1.3 概念要点（避免「概念返祖」）

•Agentic AI 综述（2510.25445）指出一个常见错误：把现代神经 Agent 硬套成旧符号模型（conceptual retrofitting）；

•正确读法：LLM Agent 是「神经派 + 工具 + 记忆」的新物种，符号派不因 LLM 出现而消失——它退到「约束/校验/规划」这些需要保证的位置。

💡 学习要点：两派不是「新旧替代」，是「能力互补」神经负责「流畅」（理解、生成、泛化），符号负责「严谨」（约束、验证、可解释）。2025-2026 的共识 = 混合——不是谁赢，是分工。

05SECTION

三、对范式选择的影响（研究 → 工程）


1需要可验证的环节（合规、财务、医疗）：让符号层把关——LLM 出草稿、符号层验证；

2需要探索的环节（创意、开放问答）：纯神经更合适；

3需要防注入的环节（Agent 联网/工具多）：符号层做确定性路由或校验（ATA 思路）——把「最关键的决定」交给不可被 prompt 污染的部分。

06SECTION

四、本篇要点（复习卡片）


1双血统：符号（MDP/BDI/SOAR——确定性可验证）vs 神经（DRL/LLM——泛化自适应）。

2各有死穴：符号僵化、神经幻觉/不可审计——互补而非替代。

3避免概念返祖：LLM Agent 是新物种，别硬套旧符号模型框架。

4混合三形态：顺序级联（ATA 防注入）/ 分层校验（合规）/ 符号增强推理（AlphaGeometry）。

52026 结论：神经符号已是成熟领域（178 篇 taxonomy）；可验证环节交符号、探索环节交神经。

07SECTION

五、下一篇预告


第 05 篇：自进化 Agent 范式——双血统解决「怎么设计对」，自进化回答「Agent 能不能自己变强」：从「一次执行」到「持续成长」（what/when/how 三问，SWE-RL 自博弈、Voyager 技能库）。范式的最新前沿：让 Agent 把执行结果变成学习信号。
