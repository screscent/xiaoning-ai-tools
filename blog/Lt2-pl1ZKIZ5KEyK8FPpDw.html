02WHY

为什么需要这条线


agent-系列讲了「一个 Agent 的构成四件套 + 机制 + 训练 + 应用 + 平台」——那是「内部解剖」。但 Agent 领域还有很多范式问题：ReAct 和 Plan-and-Execute 什么时候用？符号 AI 和神经 AI 的争论怎么影响 Agent？Copilot 和 Autopilot 到底差在哪？这些是「设计模式与发展路线」层面的知识，值得单独一条线。

03SECTION

调研结论（2026-10 快照）


•工程范式谱系：CoT（提示）→ ReAct（推理-行动交错）→ Plan-and-Execute（规划-执行分离，Planner/Executor/Verifier/Refiner）→ Reflexion（反思自修正）→ Multi-Agent（Manager-Worker 层级）→ Workflow 编排（DAG/状态机，LangGraph）——从「一个循环」到「一套工程」。

•研究范式双血统（Agentic AI Survey 2510.25445）：符号派（MDP/POMDP/BDI/SOAR，确定性决策）vs 神经派（DRL/LLM，生成式自适应）——2025-2026 趋势是混合架构（神经符号结合）。

•自进化范式（Self-Evolving Survey 2507.21046）：what（模型/上下文/工具/架构）/ when（测试内/测试间）/ how（奖励/示范/群体）——2026 年 SWE-RL 自博弈在 SWE-bench +10.4pp。

•神经符号（Neuro-Symbolic）：神经层管感知与生成、符号层管约束与可验证（ATA 框架确定性推理防注入）——2026 已成 178 篇论文的成熟领域。

•通用框架（李航 JCST 2026）：Agent = 任务导向 × 多模态输入输出 × LLM 推理 × RL 构建 × 工具与记忆——覆盖软件 Agent 与机器人。

•应用范式：Copilot（助手，人在回路）vs Autopilot（自主，监督式放权）；Workflow（确定性流水线）vs Agent（动态决策）；2026 被定义为 Agent 商用元年（MCP/A2A 标准化、行业落地规模化）。
