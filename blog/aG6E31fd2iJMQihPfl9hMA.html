视角 1：工程范式（怎么搭）

看 Agent 的控制结构演化——从「一个提示技巧」到「一套工程体系」：

05SECTION

三、三个关键范式命题（贯穿全系列）


1推理和行动要不要分开？ ReAct 说「交错」，Plan-and-Execute 说「先全盘规划再执行」——两者对成本、可预测性、出错恢复的取舍完全不同（01-02 篇）；

2符号和神经要不要结合？ 纯 LLM 流畅但不可靠，纯符号严谨但僵化——神经符号怎么分工（04-06 篇）；

3人应该在哪？ Copilot（人在主导）→ Autopilot（机器主导）——自主度怎么渐进（07-08 篇）。

06SECTION

四、本篇要点（复习卡片）


1三视角：工程（怎么搭）/ 研究（为什么对）/ 应用（拿来干嘛）——同一范式三张脸。

2工程谱系：CoT→ReAct→P&E→Reflexion→Multi-Agent→Workflow；主轴 = 确定性 vs 灵活性。

3研究双血统：符号（可验证）vs 神经（泛化）→ 混合（神经符号）是 2025-2026 共识。

4应用谱系：对话→Copilot→自主 Agent→Autopilot；工作流→Agent→混合。

5三命题：分不分开（推理/行动）、结不结合（符号/神经）、人在哪（Copilot/Autopilot）。

62026 定位：Agent 商用元年——标准化 + 行业落地。
