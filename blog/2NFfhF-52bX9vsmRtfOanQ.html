01SECTION

第 03 篇 · Claude 4：混合推理、计算机使用与 Agent 平台

02SECTION

导读

2025 年 2 月的 Claude 3.7 Sonnet 先开了「Extended Thinking」的口子，5 月的 Claude 4 家族（Opus 4 / Sonnet 4）把它做成标准能力，并放出两张王牌：Computer Use（模型自己操作电脑） 和 Claude Code（编程 Agent）。这一代，Claude 正式从「对话助手」转型为「能干活的基础设施」。

03SECTION

一、混合推理：Extended Thinking

1.1 是什么

•模型支持两种模式：普通模式：快速直接回答（日常对话）；Extended Thinking：先输出隐藏推理过程（思考），再给答案；

•用户/开发者可控制思考预算（budget_tokens）——想多久花多少，深度与成本可调。

1.2 意义

•与 o1 的「必须想」不同，Claude 是「默认会答、按需深想」——一条模型两条能力（对应 llm-理论 05 的融合趋势）；

•长程任务受益最大：规划、排错、复杂编码时「先想后做」显著降低返工。

💡 学习要点：混合推理 =「对话与思考不分家」用户无需判断「该用哪个模型」——同一模型快慢自洽。这是 2025 年所有旗舰的共同终点（GPT-5、Gemini、V4 皆如此）。

04SECTION

二、Computer Use（2024-10 起，2025 爆发）

2.1 是什么

•模型被训练成像人一样操作电脑：看屏幕截图 → 决定点击/输入/滚动 → 执行 → 再看结果；

•基准：OSWorld（真实桌面任务）——Claude 4 首次突破 40%+，Sonnet 4.5 到 61.4%（对照：四个月前 42.2%）；

•应用：Claude for Chrome（浏览器自动填表/整理/购物流程）、桌面自动化。

2.2 技术要点

•训练：大量「屏幕 → 操作」合成轨迹数据 + 强化学习；

•架构：视觉理解（截图）+ 工具调用（点击/键入）+ 长程记忆（上下文追踪）三者打通；

•局限：界面变化敏感、操作偶发漂移——但方向确定：模型正在获得「手脚」（llm-理论 06 的 Agent 三拼图）。

05SECTION

三、Claude Code 与 MCP：Agent 平台

组件

作用

Claude Code

终端里的编程 Agent：读代码库、改文件、跑测试、提 PR——自然语言驱动开发

MCP（Model Context Protocol）

开放协议：把「工具/数据源」统一接入模型（数据库、浏览器、内部系统）

Claude Agent SDK

把 Claude Code 的底层能力开放给开发者自建 Agent

•影响：MCP 成为行业「工具接入」事实标准（多家公司/框架跟进）；

•形态：从「Chat 应用」→「开发者基础设施」——Anthropic 把「Agent 平台」做成了商业模式。

06SECTION

四、安全配套：ASL 与系统卡

•发布按 ASL（AI 安全分级） 管理：Claude 4 达到 ASL 3 标准才放行；

•系统卡公开：能力、风险、对齐测试、红队结果、可解释性分析（mechanistic interpretability 首度大规模商用）；

•意义：能力越强的 Agent，安全门槛越高——对齐优先的路线在此兑现。

07SECTION

五、本篇要点（复习卡片）

1Extended Thinking：混合推理——快速答 + 按需深想，思考预算可调。

2Computer Use：模型像人一样操作电脑；OSWorld 40%→61.4%（4.5）；「手脚」成型。

3Claude Code + MCP：编程 Agent + 开放工具协议 = Agent 平台（行业事实标准）。

4Agent SDK：底层能力开放，开发者自建 Agent。

5ASL 分级 + 系统卡：对齐优先在 Agent 时代落地为发布门槛。

08SECTION

六、下一篇预告

第 04 篇：Sonnet 4.5 与 Opus 4.5——2025 年下半年的「对齐巅峰」：Sonnet 4.5（9 月）被官方称为「史上最对齐模型」，SWE-bench/计算机使用双第一；Opus 4.5（11 月）以 25 把旗舰级长程 Agent 能力做便宜，30 小时自主任务稳如老狗。Claude 系列用「安全 + 会干活」定义了 2025 年 Agent 时代的旗舰标准。
